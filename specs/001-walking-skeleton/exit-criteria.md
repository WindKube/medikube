# Phase Exit Criteria — walked (T309, T325)

Hand-maintained, unlike `traceability.md`: this is a judgment call against `plan.md`'s eleven
criteria, not a mechanical join. Each entry states proven/unproven and where. Written from this
worktree, which has no browser and no network access to a container registry — several criteria
require both and are recorded as unproven for that reason, not glossed over.

1. **All 54 acceptance scenarios pass, and `traceability.md` joins FRs, SCs and scenarios with no
   empty row.** UNPROVEN as a whole. `traceability.md` (generated by
   `internal/architecture/traceability_test.go`) has no empty row for any FR or SC, but 12 of the
   54 acceptance scenarios are recorded in `scenarios_test.go`'s `missingScenarios` ledger rather
   than proven — 5 are Playwright-only assertions not visible to a Go source walk, 3 are gaps this
   phase has not closed (US1-S5, US1-S6, US2-S12, US3-S8), and US6-S3 waits on
   `internal/httproute/gate_test.go`, which does not exist in this worktree.
2. **Every clinical operation has an owner-succeeds / stranger-refused pair.** PROVEN.
   `internal/architecture/authz_coverage_test.go` (T302) asserts every route touching clinical
   data appears in `RunOwnershipMatrix`, and it passes.
3. **`medikube routes`, `api/openapi.json` and Playwright coverage agree in both directions.**
   PARTIALLY PROVEN. `internal/openapi/staleness_test.go` proves the OpenAPI document matches the
   registry. The three-way agreement including Playwright's own page list
   (`internal/httproute/gate_test.go`, T294) is not present in this worktree — recorded as
   US6-S3's unproven reason.
4. **The Playwright gate passes on all 9 pages and 3 error views at both viewports.** UNPROVEN
   here. No browser is available in this environment; `e2e/` exists and is wired into CI
   (`.github/workflows/go.yaml`), but this worktree cannot run it to confirm.
5. **The gate has been demonstrated to go RED, twice, recorded in `e2e/README.md`.** UNPROVEN.
   `e2e/README.md` documents how to run the suite but T306 (capturing the two red-gate
   demonstrations) is not done, and this worktree has no browser to perform them.
6. **A CI job holds an SSE stream open for more than five minutes and it survives.** PROVEN as a
   wired gate: `.github/workflows/go.yaml`'s `stream-liveness` job runs `task test:sselive` with a
   25-minute job timeout, and `internal/architecture/ci_workflow_test.go` (T303) asserts the job
   exists, is not shadowed by `GOTOOLCHAIN=local`, and every other gate is wired in. The stream
   itself was not re-run end to end from this worktree (25 minutes is longer than this task
   session's practical budget); the job's presence and correctness under `go vet`/`go build` is
   confirmed instead.
7. **Zero personal/clinical content in logs, metrics, traces and Sentry after exercising every
   endpoint.** PROVEN by `internal/testsupport/phileak` (`task test:phileak`, US3-S5), which is a
   build-tagged exercise against every endpoint with sentinel data and an empty `knownLeaks`
   register (see `docs/spec-defects.md`'s D-27 entry). T313's manual review of every zerolog call
   site in `internal/` found nothing beyond opaque ids, counts and component names — no offender.
8. **Password recovery demonstrated end to end against a mail sink, and refused plainly with the
   operator warned when mail is unconfigured.** PARTIALLY PROVEN. The refusal paths are Go tests
   (`TestEveryRecoveryRequestIsAnsweredIdentically`, `TestARecoveryLinkSetsThePasswordAndEndsEverySessionBeforeIt`,
   `TestEveryUnusableRecoveryLinkIsAnsweredTheSameWay`, `TestAnInstanceThatCannotSendMailRefusesTheRequest`)
   and pass. `e2e/recovery.spec.ts` exists for the mail-sink demonstration but was not run here —
   no browser available. The start-up warning for unconfigured mail is recorded as US2-S12's
   unproven gap in `traceability.md`.
9. **`task check` is clean, and `depguard`/`forbidigo` proven to fire on a deliberate violation
   then reverted.** PARTIALLY PROVEN. `task lint:go` is 0 issues and the full suite passes with
   `-race` in this worktree. `internal/architecture/lint_config_test.go` (T298, T299) asserts the
   configured deny lists still name the forbidden imports and patterns, which is evidence the
   rules exist and are wired — it is not the same as a recorded demonstration of a reverted
   violation actually failing CI, which this task did not perform.
10. **A container image is produced from a clean checkout by the shared pipeline, no manual
    step.** UNPROVEN here. Docker is present in this environment but T305 (verifying the real
    pipeline end to end) is unchecked and out of this task's scope; not attempted.
11. **`quickstart.md` run end to end on a clean machine by someone who did not write it, ten
    minutes.** UNPROVEN. T308 is unchecked. `internal/config/documented_test.go` proves the
    document's environment variables match the config struct exactly, but the timed walkthrough
    itself has not been performed.

**Summary**: 2 of 11 fully proven (2, 6-as-gate/7), several partially proven with a named gap, and
four (4, 5, 10, 11) require a browser, a timed human walkthrough, or a container registry this
environment does not have. None of these four should be asserted as done until someone runs them
for real.
